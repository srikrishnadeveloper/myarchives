# myArchives

Frontend for the **Archives** system — a web app for storing, viewing, and managing timestamped numerical data. Pairs with the **[myarchivesbackend](https://github.com/srikrishnadeveloper/myarchivesbackend)** API.

## Stack

Built with **Lovable** — React + TypeScript + Vite, styled with Tailwind CSS and the shadcn/ui component set. The backend uses Supabase with realtime updates.

## Getting started

```bash
npm install
npm run dev      # dev server
npm run build    # production build
```

## Related

- **Backend:** [myarchivesbackend](https://github.com/srikrishnadeveloper/myarchivesbackend) — Supabase-backed service that stores and manages numerical data with timestamps.

## Development

Scaffolded with [Lovable](https://lovable.dev); can be edited in the Lovable editor or locally with Node.js + npm.
